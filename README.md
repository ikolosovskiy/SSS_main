# БФ «Стабілізейшен Суппорт Сервісез» — головна сторінка (прототип)

Статичний прототип нової головної сторінки sss-ua.org за гайдлайном SSS 2026.
Без збірки й залежностей — працює на GitHub Pages «як є».

## Структура

Усі файли лежать в одній папці (без підпапок), щоб їх можна було завантажити через веб-інтерфейс GitHub:

```
index.html        — сторінка
style.css         — стилі (кольори, шрифт Raleway, анімації)
main.js           — переліт логотипа, лічильники, поява напрямів, меню
hero-forum.jpg    — фото першого екрана
logo26.png        — логотип
star-amber.png, star-yellow.png, flower-amber.png — брендові фігури
favicon.png       — іконка вкладки
```

## Публікація на GitHub Pages

1. У репозиторії натисніть **Add file → Upload files**, виділіть усі файли цієї папки й перетягніть їх у вікно, потім **Commit changes**.
2. У репозиторії: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Оберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
4. За 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Усі шляхи відносні, тому сторінка працює і в підпапці репозиторію, і на власному домені.

## Перегляд локально

Відкрийте `index.html` у браузері або запустіть у цій папці:

```
python3 -m http.server 8000
```

і перейдіть на http://localhost:8000.

## Що варто знати

- Шрифт Raleway підвантажується з Google Fonts.
- Пошук у меню веде на пошук основного сайту (`https://sss-ua.org/?s=…`).
- Посилання з `href="#"` — заглушки: замініть на адреси відповідних сторінок.
- Анімації, прив'язані до прокрутки (поява опису фонду слово за словом, обертання фігур), працюють у Chrome, Edge і нових Safari; в інших браузерах сторінка показується одразу в готовому вигляді.
- Якщо в системі увімкнено «Зменшити рух», анімації вимикаються.
